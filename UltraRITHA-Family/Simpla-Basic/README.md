# Simpla, Basic and Basic+

Entry-level UltraRITHA controllers based on ESP32-C3: Simpla (no display), Basic (1.3" OLED) and Basic+ (in development, adds pH measurement and dosing).

## Free files / File gratuiti

Free files are in the [`Free/`](Free/) folder. They will be added as soon as they are ready.
