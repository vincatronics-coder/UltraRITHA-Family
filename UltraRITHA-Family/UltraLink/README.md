# UltraLink

UltraLink is the RS485 communication layer shared by the whole UltraRITHA family: it connects the master unit to displays, inputs and outputs, smart probes and lighting fixtures.

The protocol specification will be published here when it is ready.

La specifica del protocollo verrà pubblicata qui quando sarà pronta.
